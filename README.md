## What I’m building

### 가뿐 · Gappun
**A social media toolkit for marketers.** Gappun brings content creation and social media management into one place. Marketers can create card news and carousel posts, schedule Instagram content, and automate replies and DMs triggered by comments.

[Visit Gappun →](https://gappun.co.kr/)

### Fairway Studio
**Design a golf course, then play it.** Start with a plain-language description and customize a generated layout by adjusting bunkers and water hazards. Explore the course in 3D, play it yourself, or generate an aerial view.

### OpenClaw Workspace
**My personal OpenClaw setup.** I use OpenClaw on my PC to work with GPT, Claude, and Gemini. This workspace keeps assistant instructions and reusable workflows together, with scripts to save and sync working context.
